# 세연이의 냠냠 동물식당

3살 아이를 위한 모바일 세로형 먹이 주기 놀이입니다. 음식 그림을 한 번 누르거나 친구의 몸으로 끌어다 주세요. 글을 읽지 않아도 말풍선 그림을 보고 놀 수 있습니다.

## 실행

Node.js 22.12 이상이 필요합니다. PowerShell:

```powershell
cd C:\dev\seyeon-animal-restaurant
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 개발 서버에서는 PWA 캐시를 사용하지 않습니다.

오프라인 기능을 포함한 완성 빌드:

```powershell
npm run build
npm run preview
```

`http://127.0.0.1:4173`에 처음 접속해 캐시가 준비되면 이후 인터넷 없이도 다시 열어 놀 수 있습니다. 오프라인 효과음은 Web Audio로 기기에서 생성합니다. 설치는 Chrome의 설치/홈 화면 추가 메뉴를 사용합니다. 실제 휴대전화에서 PWA 설치와 오프라인 캐싱을 사용하려면 HTTPS 또는 휴대전화 자체의 localhost가 필요합니다. PC의 사설 IP에 HTTP로 접속하는 것만으로는 PWA가 활성화되지 않습니다.

## 놀이

- 토끼 토토/당근 → 원숭이 몽몽/바나나 → 판다 팡팡/대나무, 두 번씩 총 6회입니다.
- 음식은 매번 섞이며 같은 정답 위치가 3회 연속 나오지 않습니다.
- 오답은 감점 없이 되돌아옵니다. 두 번 오답 또는 8초 무입력 뒤 그림 힌트를 줍니다.
- 토토는 귀를 쫑긋하며 두 번 점프, 몽몽은 볼을 부풀리고 두 번 손뼉, 팡팡은 몸을 흔들며 하트를 띄웁니다.
- 정답 연출을 탭하면 짧게 건너뜁니다. 최초 350ms 및 화면 전환 중에는 연속 터치를 무시합니다.
- 꽃 6송이를 모으면 세 친구가 함께 축하합니다. 큰 원형 화살표로 다시 시작합니다.
- 스피커 버튼으로 소리를 켜고 끕니다. 저장하는 정보는 음소거 여부뿐입니다.
- 작은 모바일 가로 화면은 세로 사용 안내를 표시합니다. 큰 PC·태블릿 창에서는 가운데 세로형 게임을 바로 플레이할 수 있습니다. 움직임 줄이기 설정을 지원합니다.

의인화된 동물 친구의 놀이이며, 전문적인 동물 식성 학습 도구는 아닙니다. 계정, 광고, 결제, 분석, 외부 폰트·이미지·API 요청은 없습니다.

## 테스트

```powershell
npx playwright install chromium
npm run check
```

`check`는 단위 테스트 → 타입 검사/프로덕션 빌드 → Playwright Chromium E2E를 차례로 실행합니다. E2E는 `4173`에서 완성 빌드를 자동 실행합니다. 기존 서버가 있다면 현재 빌드를 제공하는지 확인해 주세요.

스크린샷: `qa/screenshots/`. 최종 검증과 남은 한계: [QA_REPORT.md](docs/QA_REPORT.md). 실패 시 `playwright-report/`와 `test-results/`에 보고서·트레이스를 남깁니다.

## 개발 범위

Vite + React + TypeScript, 단일 reducer, Pointer Events, 직접 제작한 SVG 및 CSS 애니메이션, Vite PWA/Workbox 캐시를 사용합니다. 원본 SVG는 React 컴포넌트로 포함됩니다. [게임 사양](docs/ai/GAME_SPEC.md)을 참고하세요.

독립 로컬 Git 저장소/`codex/animal-restaurant` 브랜치입니다. 기존 게임 파일을 사용하거나 수정하지 않았으며, 원격 저장소 생성·푸시·배포는 하지 않습니다.
