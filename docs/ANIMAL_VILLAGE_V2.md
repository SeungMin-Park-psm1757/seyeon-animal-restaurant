# 냠냠 동물마을 v2 — 확장 개발 기록

## 변경 내용
- 기존 **먹이 주기·드래그·오답 힌트·꽃 보상·6회 축하·PWA**를 보존한다.
- 별도 순수 상태 관리 `src/game/playEvents.ts`를 추가하여 미니게임 상태를 독립적으로 처리한다.
- **비눗방울, 쓰다듬기, 토끼 점프, 원숭이 박수, 판다 구르기, 숨바꼭질**의 여섯 가지 터치 놀이를 지원한다.
- 각 동물에게 3종의 랜덤 자율 모션을 추가했다. 이전 모션 연속 중복은 방지한다.
- 게임 중 오른쪽 **놀자!** 버튼으로 놀이를 시작한다. 입력이 20초 없으면 새로운 놀이를 제안한다.
- 이벤트 중 먹이 버튼을 잠시 비활성화한다. 상단 X로 언제든 밥 주기로 돌아갈 수 있다.
- 이벤트 성공 후 짧은 축하를 재생하고 원래 먹이 주기로 자동 복귀한다.
- 기존 6회 완료 후에도 **계속 놀기**를 눌러 반복할 수 있으며, **다시 놀기**는 놀이 이력을 초기화한다.

## 이벤트 진입 및 중단 원칙
- 이벤트와 먹이 주기를 동시에 실행하지 않는다.
- 캐릭터별 미니게임 제한 및 보상 조건은 별도 순수 함수로 검증한다.
- 이벤트는 패배·시간제한·감점 없이 진행한다.
- 이벤트 진행 중 앱 백그라운드 전환·회전 등은 별도 실제 모바일 QA에서 검증한다.

## 보존한 UI
기존 메인 캐릭터 SVG 및 음식 카드 크기를 그대로 사용하고, 화면 가장자리에 놀이 버튼과 오버레이를 추가했다.

## 추가 검증 필요
1. 실제 Android 터치·효과음·PWA 재설치 및 복구
2. 실제 3세 아이의 놀이 반응 및 표현 선호도 (그래픽/모션 보완과 브라우저 QA는 아래 기록 참고)
3. 전체 스크린리더 탐색, 장시간 플레이·배터리 성능 (320×568 배치 및 키보드/모션 감소 검사는 자동 QA에 포함)
4. 동물 마을 후속 이벤트: 얼굴 닦기·잠재우기·풍선·선물상자·오리 방문·무지개
5. 반복 게임에서 누적 꽃밭·스티커 보상

## 실행
`npm ci`, `npm run check`로 타입·단위·브라우저 검사를 수행한다.
`main`에 합치기 전 PR 검증 성공을 확인한다.

## 그래픽·모바일 UX 보완 (PR #1, 2026-10-09)

- `feat/animal-village-play-v2`에서 작업한다. `playEvents.ts`/`idleMotions.ts`의 이벤트 선택·보상·자율 모션 엔진은 보존한다. main 병합 및 Pages 배포는 하지 않는다.
- SVG 귀·코·눈·손·꼬리·배를 분리해 예비 동작, 반동, 정착 자세를 적용했다. 자율 모션의 전체 길이는 기존 1초 표시 시간 안에서 끝난다. 다른 동물에 이전 자율 모션이 전달되지 않도록 렌더링을 제한한다.
- 여섯 놀이에 오리지널 SVG 아이콘, 개별 반응, 파티클과 짧은 로컬 효과음을 적용했다. 비눗방울은 반투명 SVG와 빛 반사/다색 테두리, 실제 터치 위치의 팝 효과를 사용한다. 숨바꼭질은 꽃 덤불 뒤에 숨고 덤불이 양쪽으로 열리며 드러난다. 모션 감소 설정에서는 덤불을 즉시 숨긴다.
- 놀이 안내는 주문 말풍선 자리를 사용해 캐릭터 머리를 가리지 않는다. 동물 이름은 단어 단위 두 줄로 표시한다. 캐릭터·음식 SVG의 기본 크기는 유지한다.
- 320px 버튼 초점에 따른 가로 이동은 최상위 영역의 `overflow: clip`으로 방지한다. 작은 화면의 쓰다듬기 안내를 발 아래로 옮긴다.
- 검증 결과와 전후 캡처는 [QA 보고서](QA_REPORT.md)의 v2 보완 항목에 기록한다. 실제 Android, 시스템 오디오 청감 및 아이의 놀이 반응은 자동 검사 대상이 아니다.
